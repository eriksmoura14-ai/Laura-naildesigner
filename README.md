# Studio Bella Unhas – Site de Nail Designer

Site em HTML, CSS e JavaScript puros, com agendamento que redireciona para o WhatsApp.

## Como usar

Abra o `index.html` no navegador. Não precisa instalar nada.

## Personalização

Edite o bloco `CONFIG` no topo do `script.js`:

- `whatsappNumber`: número com código do país e DDD, só números (ex.: `5511999999999`)
- `studioName`: nome do estúdio, usado na mensagem
- `schedule`: dias e horários de atendimento
- `slotMinutes`: intervalo entre horários

Textos, preços, endereço e Instagram ficam no `index.html`.

## Publicar com GitHub Pages

Em **Settings → Pages**, escolha a branch `main` e a pasta `/ (root)`.
